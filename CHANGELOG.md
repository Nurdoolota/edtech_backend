## Базовая версия — до начала практики

### 2026-04-10

#### Добавлено — Первоначальная реализация

**Общая инфраструктура**
- Инициализация многомодульного Maven-проекта с общей конфигурацией.
- PostgreSQL как единая база данных; Flyway-миграции в сервисе аутентификации:
  - `V1` — таблицы ролей, пользователей, аудита делегирования сессий.
  - `V2` — таблицы курсов, групп, заданий, результатов, шаблонов промптов.

**Шлюз (порт 8080)**
- Маршрутизация запросов на сервисы аутентификации, контента и обучения.
- Проверка JWT-токена; передача идентификатора и роли пользователя во внутренние сервисы.
- Глобальные фильтры: идентификатор запроса `X-Request-Id`, CORS, ограничение частоты запросов.
- Открытые точки доступа без токена: регистрация, вход, обновление токена.
- Документация OpenAPI/Swagger; проверка работоспособности через Actuator.

**Сервис аутентификации (порт 8081)**
- Регистрация — роль фиксирована «Студент»; пароли хранятся в виде BCrypt-хэша.
- Вход — выдача токена доступа и токена обновления.
- Обновление токенов.
- Получение данных текущего пользователя.
- Административные операции: список пользователей с постраничной разбивкой, смена роли и блокировка, делегирование сессии (вход от имени другого пользователя) с аудитом.

**Сервис контента (порт 8082)**
- Управление курсами: список с фильтрацией по роли, создание, обновление, удаление.
- Управление учебными группами: добавление и удаление студентов, привязка курсов.
- Управление заданиями с проверкой структуры содержимого по типу: `FILL_BLANKS`, `TRUE_FALSE`, `VIDEO`, `TEXT`, `TRANSLATION`, `DEBATES`.
- Внутренняя точка доступа для сервиса обучения: проверка права студента на выполнение задания через группы.

**Сервис обучения (порт 8083)**
- Приём ответа студента с проверкой прав доступа.
- Паттерн «Стратегия» для выбора способа проверки по типу задания:
  - Проверка по ключу — `FILL_BLANKS`, `TRUE_FALSE` (без обращения к языковой модели).
  - Проверка через ИИ — `TEXT`, `TRANSLATION`, `VIDEO`, `DEBATES`.
- История результатов студента и просмотр результатов по заданию для преподавателя.
- Ручная валидация оценки преподавателем со статусом «Подтверждено преподавателем».
- Модульные тесты для всех компонентов проверки и контроллера.

**Сервис ИИ (порт 8084)**
- Внутренняя точка доступа для оценки ответа через языковую модель.
- Четыре шаблона промптов: оценка текста, перевода, видео, дебатов.
- HTTP-клиент, совместимый с OpenAI API; смена провайдера только через переменные окружения.
- Устойчивый разбор JSON-ответа модели: удаление обёрток в виде блоков кода, структурированная ошибка при некорректном ответе.
- Модульные тесты для шаблонизатора промптов и сервиса оценки.

---

### 2026-05-25

#### Добавлено — Сервис аутентификации

- **AUTH-01** — Управление профилем: редактирование имени и фамилии, деактивация учётной записи.
- **AUTH-02** — Загрузка фотографии профиля: составной запрос на сервер, статическая раздача по адресу; ссылка на фотографию включена в ответ о текущем пользователе.
- **AUTH-03** — Смена пароля с проверкой текущего и обновлением хэша.
- **AUTH-04** — Переключаемый почтовый сервис с шаблонами Thymeleaf: режим реальной отправки через SMTP и режим вывода в журнал для среды разработки; выбор через переменную окружения.
- **AUTH-05** — Восстановление пароля: запрос отправляет письмо с одноразовой ссылкой; подтверждение применяет новый пароль по токену со временем жизни 15 минут.
- **AUTH-06** — Смена адреса электронной почты в два шага: запрос отправляет письмо с токеном подтверждения, подтверждение применяет новый адрес.
- **AUTH-07** — Административная точка доступа для просмотра журнала вызовов ИИ-сервиса с постраничной разбивкой.

### 2026-05-28

#### Добавлено — Сервис ИИ

- **AI-01** — Проверка работоспособности: контрольный запрос к провайдеру языковой модели с возвратом статуса доступности и измеренной задержки.
- **AI-02** — Повтор запроса при сбое провайдера с нарастающей задержкой между попытками; восстановление повреждённых JSON-ответов модели с удалением обёрток в виде блоков кода.

- **AI-04** — Генерация учебного контента: формирование текстов заданий на основе шаблонов и пользовательских параметров.

#### Добавлено — Сервис обучения

- **LEARN-03** — Внутренние точки доступа для межсервисного взаимодействия: результаты по заданию и статистика прогресса студента.
- **LEARN-04** — Поддержка загрузки аудиофайла для типа задания `SPEAKING`; путь к файлу сохраняется в результате ответа студента.
